## 🎯 Objetivos del Repositorio

1.  **Dominio de Fundamentos:** Completar el reto NeetCode 150 entendiendo la complejidad temporal ($O(n)$) y espacial de cada solución.
2.  **Pensamiento de Arquitecto:** Documentar no solo *cómo* funcionan las herramientas, sino *cuándo* y *por qué* usarlas en sistemas distribuidos.
3.  **Documentación Robusta:** Mantener explicaciones claras y diagramas que sirvan como referencia rápida en el futuro.
